# Documentation / 文档

Every document has a language switch at the top. User-facing documents are available in
English and Simplified Chinese; internal design records are currently Chinese-only.

每篇文档顶部都有语言切换。面向用户的文档提供英文与简体中文；内部设计记录目前只有中文。

| Changelog | [CHANGELOG.md](../CHANGELOG.md) | [CHANGELOG.zh-CN.md](../CHANGELOG.zh-CN.md) |
| Release checklist | [RELEASE.md](RELEASE.md) | [RELEASE.zh-CN.md](RELEASE.zh-CN.md) |

| M1a report | — | [M1A-REPORT.md](M1A-REPORT.md) |

Conventions:

- Filenames use the `*.zh-CN.md` suffix for the Chinese version; the English version keeps
  the original name.
- Both versions start with `[English](…) | [简体中文](…)`; keep the pair in sync when the
  document changes.
- Code, commands, tool names, file paths, and decision IDs are not translated.

约定：

- 中文版使用 `*.zh-CN.md` 后缀；英文版保留原文件名。
- 两个版本顶部都写 `[English](…) | [简体中文](…)`；文档变更时同步更新。
- 代码、命令、工具名、文件路径、决策编号不翻译。
